# 🐋 Dart Basics Code Repository

This repository contains a collection of folders and files focused on **basic Dart programming** concepts. It is intended to help beginners learn and understand the core syntax and fundamental features of the Dart language before progressing to more advanced topics like Flutter or backend development.

---

## 📚 Contents

Each folder in this repository represents a topic or concept in Dart, such as:

* 🔹 Variables and Data Types
* 🔹 Functions and Parameters
* 🔹 Control Flow (if, switch, loops)
* 🔹 Collections (List, Set, Map)
* 🔹 Object-Oriented Programming (OOP)
* 🔹 Error Handling
* 🔹 Null Safety
* 🔹 Recursion
* 🔹 Closures and Scope

All code examples are written in Dart and organized to be easy to understand and run individually.

---

## 🚀 Getting Started

To run any of the Dart files:

1. Make sure Dart SDK is installed.
2. Navigate to the desired folder.
3. Run the Dart file using:

```bash
dart filename.dart
```
