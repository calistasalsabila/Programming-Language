# 🐋 Dart OOP Code Repository

This repository contains folders and code examples focused exclusively on **Object-Oriented Programming (OOP) in Dart**. It is designed to help learners understand how OOP works in Dart with practical examples and structured files.

---

## 📚 Contents

Here are the core OOP concepts covered:

* 🔸 Classes & Objects
* 🔸 Constructors (Default, Parameterized, Named)
* 🔸 Inheritance
* 🔸 Method Overriding
* 🔸 `super` and `this` keywords
* 🔸 Getters and Setters
* 🔸 Encapsulation
* 🔸 Abstraction with `abstract` classes
* 🔸 Polymorphism
* 🔸 Static Members

Each folder contains Dart files demonstrating real and simplified use cases for each concept.

---

## 🚀 Getting Started

To run the examples:

1. Install Dart SDK from [dart.dev](https://dart.dev/get-dart)
2. Navigate to any concept folder
3. Run the file with:

```bash
dart filename.dart
```
