# Understanding `this` and `undefined` in JavaScript

## 1. Problem Overview

In the given code:

```js
const ROARRRRRRR = {
    firstName: "Dino",
    lastName: "Saurus",
    fullname: () => {
        return `${this.firstName}${this.lastName}`;
    },
    panggilNanti: function (){
        setTimeout(function(){
            console.log(this.firstName);
        }, 3000);
    }
};

console.log(ROARRRRRRR.fullname());
console.log(ROARRRRRRR.panggilNanti());
```

Both functions print `undefined` due to how JavaScript handles the `this` keyword.

---

## 2. Arrow Function and `this`

The function:

```js
fullname: () => {
    return `${this.firstName}${this.lastName}`;
}
```

is an **arrow function**. Arrow functions do **not** create their own `this` context. Instead, they inherit `this` from the **lexical scope** where they were defined.

Since the function is defined inside the global scope (and not inside another function that sets `this` to the object), `this` refers to the **global object** (`window` in browsers, or `undefined` in strict mode). Therefore, `this.firstName` and `this.lastName` are undefined.

Result:

```
undefinedundefined
```

---

## 3. Callback in `setTimeout`

Inside `panggilNanti`, this function is used:

```js
setTimeout(function(){
    console.log(this.firstName);
}, 3000);
```

When `setTimeout` executes, the callback function runs with its own `this` value, which by default refers to the **global object**, not the object `ROARRRRRRR`. As a result, `this.firstName` is undefined again.

---

## 4. Correct Approaches

### Method 1: Use Arrow Function in `setTimeout`

Arrow functions inherit `this` from their surrounding scope. Thus:

```js
panggilNanti: function () {
    setTimeout(() => {
        console.log(this.firstName);
    }, 3000);
}
```

Output after 3 seconds:

```
Dino
```

### Method 2: Store `this` in a Variable

Before ES6, a common approach was:

```js
panggilNanti: function () {
    const self = this;
    setTimeout(function(){
        console.log(self.firstName);
    }, 3000);
}
```

### Method 3: Use `bind(this)`

The `bind()` method explicitly binds the `this` value for the callback:

```js
panggilNanti: function () {
    setTimeout(function(){
        console.log(this.firstName);
    }.bind(this), 3000);
}
```

---

## 5. Complete Fixed Code

```js
const ROARRRRRRR = {
    firstName: "Dino",
    lastName: "Saurus",
    fullname: function (){
        return `${this.firstName} ${this.lastName}`;
    },
    panggilNanti: function (){
        setTimeout(() => {
            console.log(this.firstName);
        }, 3000);
    }
};

console.log(ROARRRRRRR.fullname()); // "Dino Saurus"
ROARRRRRRR.panggilNanti();          // After 3 seconds -> "Dino"
```

---

## 6. Summary Table

| Case                           | Why `undefined` Occurred         | Correct Fix                              |
| ------------------------------ | -------------------------------- | ---------------------------------------- |
| `fullname` with arrow function | Arrow function has no own `this` | Use regular function syntax              |
| `setTimeout` callback          | Callback gets global `this`      | Use arrow function, bind, or save `this` |
