# JavaScript Modules Overview

This repository is divided into multiple submodules for structured JavaScript learning:

* **01_js_basic** — Covers JavaScript fundamentals such as variables, data types, operators, conditions, loops, functions, arrays, and objects.
* **02_js_oop** — Focuses on Object-Oriented Programming (OOP) concepts: object literals, constructors, prototypes, classes, and inheritance.
* **03_js_asychronus** — Explores asynchronous JavaScript: callbacks, promises, async/await, and Fetch API.
* **04_js_dom** — Teaches DOM manipulation: element selection, event handling, and interaction with web pages.

Each folder includes examples, explanations, and exercises for hands-on learning.
