# JavaScript Learning Repository

This repository contains a structured learning path for mastering JavaScript fundamentals to advanced concepts. Each folder focuses on a specific area of JavaScript, starting from basic syntax to working with the Document Object Model (DOM).

## Folder Structure

### 1. `01_js_basic`

This section covers the **foundations of JavaScript**, such as:

* Variables and Data Types
* Operators
* Conditional Statements
* Loops
* Functions
* Arrays and Objects

Purpose: To build a solid understanding of the language syntax and basic logic structures.

### 2. `02_js_oop`

Focuses on **Object-Oriented Programming (OOP)** in JavaScript. Topics include:

* Object Literals
* Constructor Functions
* Prototypes and Inheritance
* ES6 Classes
* Encapsulation, Polymorphism, and Abstraction

Purpose: To understand how JavaScript implements OOP principles and how to organize code efficiently.

### 3. `03_js_asychronus`

Covers **asynchronous programming** in JavaScript, including:

* Callbacks
* Promises
* Async/Await
* Fetch API
* Error Handling in Asynchronous Code

Purpose: To manage operations that take time to complete, such as API requests or file reading, without blocking the main thread.

### 4. `04_js_dom`

Focuses on **Document Object Model (DOM) manipulation**, which is essential for web development. Topics include:

* Selecting and Modifying Elements
* Event Handling
* Creating and Removing Elements
* Working with Forms and Inputs
* Understanding the Browser Environment

Purpose: To enable interaction between JavaScript and web page elements for building dynamic web applications.

## Goal of This Repository

The main objective is to build a strong foundation in JavaScript — from core syntax to interactive web functionalities — serving as a complete guide for beginners and intermediate learners.

## Recommended Learning Flow

1. Start with `01_js_basic` to understand the language fundamentals.
2. Continue to `02_js_oop` to learn structured programming.
3. Move to `03_js_asychronus` to handle real-world asynchronous operations.
4. Finish with `04_js_dom` to connect JavaScript with HTML and CSS for interactive projects.
